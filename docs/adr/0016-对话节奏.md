# 对话节奏：一次一个动作，欠账不糊脸

`preset/skills/learning-system/SKILL.md` 的会话节奏补上五条硬约束，都是同一个来源：**注意力稀缺的读者
在对话里掉线，不发生在「讲得不对」上，而发生在「不知道该做哪一件」上**。

- **开场 ≤3 行**：一句恢复（上次做到哪）、一行键值状态、一个动作。原来的开场要求「报上次学到哪、建议
  学什么、报清节点数与课型」，一段话里塞了四件事，读者读完还不知道要干什么。
- **跨天或断更回来不列欠账**：只给一句前情加一个**两分钟能做完**的微动作，欠账等学生主动问。回来的第一屏
  如果是一张欠账单，他下次就不回来了——而欠账一条都没少，只是从开场挪到了学生问的时候。
- **一次只给一个动作，并带分钟数**：并列两个选项（"要么复习错题、要么开新课"）时，常见的反应是都不选。
  真要分叉，先替他选一条，再给一句"不想这样就直说"。
- **选择类问题配默认项**（"不想选就按这个走"），**事实与自评不配**：前置基础的档位必须学生自己报，
  替他填等于污染数据——这条是默认项机制的边界，不是建议。
- **岔题先答再停车**：学生中途聊到别处，先用一两句答完，回复末尾挂一行 `停车：〈话题〉`，本节收尾（或本次会话结束）前
  回访一次。停车场只停这次会话，**不落盘**——它是工作记忆的替身，不是新的档案。
- **卡住先换媒介、再降难度**：第一次换讲法（画出来／换类比／让他动手试／指速查页），第二次才降练习档位。
  原来只写「连续两次无效就把练习降一档」，等于第一次就到降难度，学生会觉得「我被降级了」。
- **收尾最多三项**："下次从这继续"写到三项以上等于没给方向。

## Considered Options

- **不改，靠人格化口气解决**：口气能让人愿意读，但解决不了「四个选项摆在一起」这种结构性问题。
- **把开场做成模板填空**：能压到三行，但模板会退化成汇报格式（"进度／建议／下一步"三栏），第三栏仍然是
  并列建议。**选中**的是「一个动作 + 分钟数」，不是「三栏模板」。
- **把欠账清单删掉**：不删数据，只改开场措辞。进度文件里的欠账是学生主动问时的答案来源，删了就没法回答。

## Consequences

- **`learning-discovery` 一字不改**：探索阶段仍然「不标推荐、不排序暗示」（它的 52/90 行），默认项只加在
  盘问与学习路径选择上——探索的任务是扩大选择，学习的任务是收窄到一件事，两者的选项语义相反。
- **盘问的步数不能变**：`## 新科目盘问（你亲自执行）` 固定 `1.`～`7.`，且标题是 `test_skill_rules.mjs`
  的切片锚点；默认项是**加在既有第 2 步里的一句约束**，不是第 8 步。
- **`preset/qa/agent.cordis.yml` 的答疑面板不受影响**：面板本来就短、停在原地，它没有「下一步」这个位置。
- **停车场不落盘**，因此 `record-keeping` 的恢复视图看不到它；跨会话的「上次说到一半的话题」不在本 ADR 的
  范围内——那需要真正的会话摘要，属于另一件事。
