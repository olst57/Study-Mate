# 讲课人格固定：文风从「教材语体」换成不可覆盖的人格

`preset/skills/lesson-design/SKILL.md` 的第五节从「行文风格（经典教材语体）」整节换成「讲课人格与文风」，
并且这一节同时管两处：**课件正文**与**会话口气**。人格（口气、故事钩子、emoji 密度、跑题必回主线、
八条共同底线）**固定**——学生与共享记忆都覆盖不了；**讲法**（先讲什么、多深、例子来源、节奏）仍是
倾向性指引，随时可改；大纲、题目、档案这类**数据文字**中性，不受人格约束。

为什么非改不可：课件是注意力稀缺读者的主要输入，而旧口径要求「以说明为主、语气克制客观、少用口语与
情绪」。读者读到第三行就滑走的材料，讲得再准确也送不进去。更麻烦的是**可覆盖**——只要人格也算
「倾向」，它就会按学生的一句话在每个会话里重新漂移，`lesson-design` 也就不再是课件的唯一约束来源。
两层拆开之后，「声音稳定」与「按人调整」不再互斥。

**人格只写动作，不写病因。** 五个痛点（启动困难、工作记忆窄、时间盲区、多巴胺依赖、挫败敏感）的
成因留在 ADHD 适配方案（独立 docs 提交）与 ADR-0023／0024／0025 里；技能正文只写可执行的判据，
并由一条全量扫描 12 份 `SKILL.md` 的断言盯住（禁「多巴胺」「工作记忆」「挫败敏感」「学生画像」
「性格画像」「认知特征」「ADHD」「注意缺陷」，不禁既有术语「画像三节」）。理由是可观察的：病因一旦
进提示词，模型就有相当概率把它变成对学生的判断再说出口（「为了防止你分心，我只列三点」），那恰好
破坏平视的人格。

## Considered Options

- **保持教材语体**：现状不动。问题原样留着——注意力稀缺的读者被挡在第三行。
- **人格与讲法都可覆盖**（本次改造前的状态）：看着最灵活，实际是两套口径互相抵消——学生说「别用 emoji」，
  课件就退回讲义，而 §五 又要求「emoji 有密度上限」。同一份文件里两条互斥的指令，模型的反应不是二选一，
  而是**打折**：故事讲一半收住、口气收回来，写成既不够活也不够严的四不像。
- **人格固定、讲法可调**（**选中**）：稳定的是声音，可调的是路径。代价是推翻
  [设计方案](../设计/设计方案.md) §3.3 原有的「讲解风格一律写成倾向性指引」。

## Consequences

- **`设计方案` §3.3 被部分推翻**：原则从「讲法一律是倾向性指引」改成「人格硬约束 + 讲法倾向」；
  §3.5 补一句分工——人格管材料里的讲法，聊天里只给短钩子，不把讲义搬进来。
- **`templates/MEMORY.yaml` 第 4 行注释要收口**：原文「讲法偏好写在这里，优先级高于任何通用指引」
  把人格也一起放行了；改成「优先级高于任何通用**讲法**指引」，并加一层「只记学生**明确说过**的讲法
  选择，不推断他的认知特征与性格」。**旧工作区不回填**（模板只在初始化时复制一次），也**不改任何键名**
  （`test_memory_rename.mjs` 钉着三个键），只改注释不影响 `test_core_memory.mjs` 的三条模板断言
  （节名与顺序、空骨架、注释不进投影）。
- **`learning-system` 要真的加载它**：总控说话的口气与课件同源，`scripts/tests/rule-owners.json` 的
  `reaches.learning-system` 因此补上 `lesson-design`；同时把那条「够不着 `lesson-design`」的合成负例
  换成 `layered-practice`，保证机制自检仍然是活的。放宽可达不会误伤否定式断言——已核 `learning-system`
  的两条退役说法都不在 `lesson-design` 里。
- **大纲用词随之中性化**：`preset/skills/curriculum-designer/SKILL.md` 原来写「不要口语化的文字，要参考
  经典教材的文笔」，人格固定之后它会以为全系统的文字都该往教材腔走；改成「准确、可检索，不写段子、
  不写口号——人格管课堂，不管大纲」。
- **答疑预设只能自包含**：`preset/qa/agent.cordis.yml` 的技能目录只有 `preset/skills/local-qa`，读不到
  `lesson-design`，所以人设行不能写「按学习模式的讲课人格」，必须把口气那两句直接写进去；长度仍按
  `preset/skills/local-qa/SKILL.md` 的「短」——面板的「短、停在原地」优先级高于人格的展开欲。
- **旧课件不会自动变**：人格只影响新讲解与重讲；按新人格重写旧课走 `preset/skills/learning-coach/SKILL.md`
  第 3 步的「明确的新交付」例外。

这是 ADHD 适配方案（独立 docs 提交）四个功能 PR 里的第一个（PR 1）。
